## Criterio de organización

- Los documentos numerados representan el flujo principal de trabajo.
- Las carpetas temáticas conservan investigaciones paralelas y guías específicas.
- Los reportes mantienen su contenido original; solo se actualizaron rutas relativas al moverlos.
